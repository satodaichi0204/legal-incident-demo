# 法律事務所向け AI事件情報 デモ版

AI が公開情報（個人情報の漏えい、サイバー攻撃、消費者被害）を集めて整理し、出典つきの事件ページの下書きを作り、広告の確認を通って**弁護士が承認したものだけ**が、事務所専用の公開ページに出る仕組みのデモです。

- 企業、事件、法律事務所、弁護士、ニュースサイトは**すべて架空**です。実在のサイトにはアクセスしません。
- 被害者の情報は扱いません（受付は事務所の外部のフォームへのリンクだけ）。法律事務所の比較・紹介、AI による法的な評価は作りません。
- 見本モード（APIキー不要）。AI の利用量は、Claude API の料金で見積もって記録します（実際には呼びません）。

## 流れ

収集（重複のまとめ、続報の検知、取得の失敗の通知）→ 事件の候補 → 出典つきの下書き → 公開前のチェック（断定・誇大・条件のない無料・弁護士の情報・費用の条件・出典・個人の情報）→ 承認の依頼 → 弁護士の承認 → 事務所の公開ページ（SEO、OGP、構造化データ、サイトマップ、共有、外部の受付フォーム）→ 公開後の重要な変更は再承認、誤字は訂正 → 公開停止、契約の期限で自動の公開停止

## 動かし方

```bash
npm ci
npm run dev        # http://localhost:3000
npm test           # 単体テスト（Vitest）
npm run build && npm run test:e2e   # 通しのテスト（Playwright。パソコンとスマートフォン）
```

右上で利用者を切り替えると、事務所（さくら／みなと）と役割（弁護士＝承認者、事務員＝編集者）が変わります。

## 構成

| 場所 | 役割 |
|---|---|
| `src/lib/collect.ts` | 収集、重複の判定、続報と件数の変化の検知 |
| `src/lib/check.ts` | 公開前のチェック（広告の確認）と、出典の照合 |
| `src/lib/state.ts` | 承認の流れ、版、再承認、公開停止、契約の期限、通知、AI の利用量 |
| `src/lib/industry.ts` | 業種の設定（他業種への転用：リフォーム業、退職代行の例） |
| `src/lib/data.ts` | 架空のデータ |
| `src/views/`、`src/app/` | 画面。公開ページは `src/app/s/[firm]/` |

本番では、データベースと認証に Supabase（行の単位の権限で事務所ごとに分離）を使う想定です。

## 写真について

画面の写真は「ぱくたそ（https://www.pakutaso.com/）」のフリー素材です。再配布が禁止されているため、写真のファイル（`public/photos/`）はこのリポジトリに含めていません。公開先には手元から直接上げています。
